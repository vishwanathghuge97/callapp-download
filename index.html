callApp

Private calls between two phones.

No accounts. No phone numbers. Pair the two phones once, then tap a name to call.

Download for Android

Android 8 or newer, on a 64-bit phone. Not for iPhone.

Open this page on the other phone

Set up both phones

  1. 1
    Download the app

    Tap Download for Android. If Android asks, allow your browser to install unknown apps. You can turn that off again afterwards.

  2. 2
    Open callApp

    Choose Add a person on both phones.

  3. 3
    Pair the two phones

    One phone shows a code. The other scans it. Check that the long number is the same on both phones, then tap Allow on both.

  4. 4
    Check that calls can ring

    Open Settings, then Check my phone. Fix anything it flags so callApp can ring when the screen is off.

Privacy

Calls are private. Only you and the person you call can hear them. Photos stay on this phone. callApp has no accounts, no phone numbers and no ads.

Already have callApp? Open Settings, then About, then Check for updates. Only install callApp from this page.
