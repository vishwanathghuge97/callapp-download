callApp

Private calls between two phones.

No accounts. No phone numbers. Pair once with a code, then call directly over an encrypted connection.

Download for Android

Android 8 or newer

Scan this code on the other phone to open this page.

  1. Download and open the file. If Android asks, allow your browser to install unknown apps.
  2. Open callApp. Read the short welcome screen and continue.
  3. Pair the two phones. One phone shows a code; the other scans it. Then make a call.

Only install callApp from this page. If you already have callApp, use Settings → About → Check for updates inside the app.
